# Sales Data Analysis

## Overview

This project analyzes sales data using Python to identify important business insights and sales trends.

The analysis focuses on revenue, products, categories, customers, cities, payment methods, order status, and monthly sales performance.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains sales information including:

* Order ID
* Order Date
* Product
* Category
* Customer ID
* City
* Quantity
* Price
* Payment Method
* Order Status
* Revenue

## Data Cleaning

The dataset was prepared for analysis by:

* Handling missing values
* Converting date columns into the appropriate format
* Checking for invalid values
* Handling inconsistent data
* Creating calculated columns required for analysis

## Analysis

The project answers questions such as:

* What is the total revenue?
* What is the average order value?
* Which product generated the most revenue?
* Which category generated the most revenue?
* Which city generated the most revenue?
* Which payment method is used most often?
* Who are the top 10 customers by spending?
* Which month had the highest revenue?
* Which month had the lowest revenue?
* How does revenue change over time?

This project demonstrates the use of Python, Pandas, NumPy, and Matplotlib to clean, analyze, and visualize sales data and extract useful insights from a dataset.
